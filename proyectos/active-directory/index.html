Infraestructura de Active Directory

Arquitectura

Entorno del laboratorio

Servidor y clientes comparten una red virtual NAT. El controlador de dominio ofrece AD DS y DNS, y los clientes usan su IP privada como DNS preferido.

Objetivos

Qué demuestra este proyecto

  • Crear y administrar un dominio corporativo.
  • Organizar usuarios, grupos y equipos mediante OUs.
  • Integrar clientes Windows 11 en el dominio.
  • Aplicar GPO por departamento.
  • Gestionar carpetas compartidas y permisos NTFS.

Incidencia documentada

Relación de confianza rota

Síntoma: error de relación de confianza entre un cliente y el dominio.

Comprobación: revisar DNS, hora del sistema y la cuenta de equipo en Active Directory antes de aplicar cambios.

Resolución: reparar el canal seguro del cliente o sacarlo del dominio y unirlo de nuevo. Si restableces la cuenta desde Active Directory, tendrás que volver a unir el equipo.
